# Тест-план «Хлорис»

Статический лендинг без сборки: логики мало, поэтому автотест один — на проверку полей формы. Остальное проверяется чек-листом перед выкладкой.

## Автоматически

| Что | Тип | Как запустить |
|---|---|---|
| Правила полей формы (`js/validate.js`): имя, телефон (11 цифр, первая 7 или 8), комментарий до 500 знаков | Unit, `node:test` | `node --test` |

Пробел: фильтр, форма в браузере, меню и слайдер автотестами не покрыты. Если проект будет расти, следующий шаг — 3–4 сценария на Playwright (фильтр, заказ из карточки, отправка формы, меню на телефоне).

## Чек-лист перед выкладкой

Запустить `python -m http.server 5500`, открыть http://localhost:5500.

**Сценарии**
- [ ] Фильтр: «Свадьба» — 2 букета, «День рождения» — 3, «Без повода» — 3, «Все» — 8; нажатая кнопка выделена.
- [ ] «Заказать» на карточке ведёт к форме, в поле «Букет» стоит этот букет; следующий Tab попадает в «Ваше имя».
- [ ] Пустая форма: ошибки у имени и телефона, фокус на имени. Исправленное поле сразу теряет ошибку.
- [ ] Телефон `+7 900 12` — ошибка про 11 цифр; `+7 (900) 123-45-67` — принимается.
- [ ] Правильная форма: кнопка «Отправляем…», затем «Заявка принята» с именем и телефоном.
- [ ] Офлайн (DevTools → Network → Offline): сообщение «Не получилось отправить заявку», форма остаётся.
- [ ] Слайдер отзывов: «Следующий» листает на одну карточку, на краях кнопки неактивны.
- [ ] Мобильное меню: открывается, пункт закрывает меню и ведёт к секции, Esc закрывает и возвращает фокус.

**Адаптив** — 320, 375, 768, 1024, 1440 px: нет горизонтального скролла, каталог 2/2/3/4/4 столбца.

**Доступность**
- [ ] Весь сайт проходится Tab, контур фокуса виден везде, включая тёмный подвал.
- [ ] Первый Tab — «К содержимому».
- [ ] Экранная читалка (NVDA или VoiceOver): после фильтра звучит «Показано N букетов», ошибки поля читаются вместе с подписью.
- [ ] Включить «уменьшение движения» в системе: блоки не анимируются.

**Без JS** (DevTools → Disable JavaScript): все блоки видны, меню списком, фильтр и кнопки слайдера скрыты, у пустой формы срабатывает нативная проверка браузера.

**Производительность**: CLS = 0; на телефоне грузится `hero-800.webp` и карточки `-400`; вся страница меньше 1,5 МБ.
